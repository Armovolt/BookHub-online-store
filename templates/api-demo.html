🛠️ Перевірка доступності API

Пояснення статусів:

200-299 - Успішно
400-499 - Помилка клієнта
500-599 - Помилка сервера
405 - Невірний метод (GET замість POST)

📡 Інформація про API BookHub

Базовий URL API:

http://localhost:5000/api/v1
Локальний сервер
http://127.0.0.1:5000/api/v1
IPv4 адреса
Базовий URL /api/v1 сам по собі не повертає даних - це тільки префікс для всіх endpoints. Спробуйте /api/v1/books для отримання списку книг.

Основні ендпоінти:

GET /books Список книг
POST /cart Додати до кошика
POST /reviews Створити відгук
GET /search/books?q= Пошук книг

Додавання до кошика (books.html) 

// Приклад з books.html
async function addToCart(bookId) {
    try {
        const response = await fetch('/api/v1/cart', {
            method: 'POST',
            headers: {'Content-Type': 'application/json'},
            body: JSON.stringify({ book_id: bookId, quantity: 1 })
        });
        
        const data = await response.json();
        
        if (data.success) {
            BookHub.showNotification('Книга додана до кошика!', 'success');
            BookHub.updateCartCounter(data.total_items);
        } else {
            BookHub.showNotification(data.error, 'error');
        }
    } catch (error) {
        BookHub.showNotification('Помилка мережі', 'error');
    }
}

Цей код демонструє асинхронну відправку POST запиту до API кошика з обробкою відповіді та помилок.

Створення відгуку (reviews.html) 

// Приклад з reviews.html
document.getElementById('review-form').addEventListener('submit', async function(e) {
    e.preventDefault();
    
    const reviewData = {
        message: document.getElementById('review-message').value,
        rating: parseInt(document.getElementById('review-rating').value)
    };
    
    const response = await fetch('/api/v1/reviews', {
        method: 'POST',
        headers: {'Content-Type': 'application/json'},
        body: JSON.stringify(reviewData)
    });
    
    const data = await response.json();
    
    if (data.success) {
        BookHub.showNotification('Відгук надіслано!', 'success');
        document.getElementById('review-form').reset();
    }
});

Обробка форми відгуку з валідацією даних та відправкою через POST запит до API відгуків.

⚠️ Обробка помилок у API

HTTP 400 - Bad Request

Неправильний запит (відсутні обов'язкові поля)

{"success": false, "error": "Недостатньо даних"}

HTTP 401 - Unauthorized

Користувач не авторизований

{"success": false, "error": "Не авторизовано"}

HTTP 404 - Not Found

Ресурс не знайдено (книга, користувач, замовлення)

{"success": false, "error": "Книгу не знайдено"}

HTTP 500 - Internal Server Error

Внутрішня помилка сервера

{"success": false, "error": "Внутрішня помилка сервера"}
