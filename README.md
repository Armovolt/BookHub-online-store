- **Автори:** Дмитерчук Віталій Вадимович (команда "Ardoes")

## Опис проєкту
BookHub - це повноцінний веб-додаток для продажу книг онлайн з RESTful API. API дозволяє виконувати всі CRUD операції з книгами, замовленнями, відгуками та кошиком покупок. Додаток включає повну документацію Swagger та підтримує авторизацію користувачів з різними ролями.

### 1. Отримання всіх книг
- **URL:** `/api/v1/books`
- **Метод:** `GET`
- **Опис:** Повертає список усіх книг у системі
- **Приклад запиту:** `GET /api/v1/books`
- **Приклад відповіді:**

```json
      "price": 350.0,
      "category": "Фантастика",
      "stock_quantity": 15,

```

## Обробка помилок
### Список реалізованих кодів помилок з прикладами:

400 Bad Request - виникає при відправленні неправильних даних (відсутні обов'язкові поля, неправильний формат)

{
  "success": false,
  "error": "Недостатньо даних"
}
401 Unauthorized - виникає при спробі доступу до захищених ресурсів без авторизації або з неправильними обліковими даними

{
  "success": false,
  "error": "Невірний логін або пароль"
}
403 Forbidden - виникає при спробі виконати дію без достатніх прав (наприклад, звичайний користувач намагається отримати статистику)

{
  "success": false,
  "error": "Доступ заборонено"
}
404 Not Found - виникає при зверненні до неіснуючого ресурсу (книги, користувача, замовлення)

{
  "success": false,
  "error": "Книгу не знайдено"
}
500 Internal Server Error - виникає при внутрішніх помилках сервера (проблеми з базою даних, непередбачувані помилки)

{
  "success": false,
  "error": "Внутрішня помилка сервера"
}
