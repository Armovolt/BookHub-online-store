- **Версія API:** v1.0

## Опис проєкту
BookHub - це повноцінний веб-додаток для продажу книг онлайн з RESTful API. API дозволяє виконувати всі CRUD операції з книгами, замовленнями, відгуками та кошиком покупок. Додаток включає повну документацію Swagger та підтримує авторизацію користувачів з різними ролями.

## Технології

### Основні технології:
- **Python 3.14.0** - мова програмування
- **Flask 3.1.2** - веб-фреймворк
- **SQLite** - реляційна база даних (вбудована в Python)
- **Flask-SQLAlchemy 3.1.1** - ORM для роботи з базою даних

### Бібліотеки для API та документації:
- **Flasgger 0.9.7.1** - Swagger UI документація для API
- **Flask-Login 0.6.3** - система авторизації та аутентифікації
- **Flask-CORS 4.0.0** - обробка CORS запитів для API
- **Flask-WTF 1.2.2** - інтеграція з WTForms

### Додаткові бібліотеки:
- **WTForms 3.2.1** - валідація форм
- **email-validator 2.1.0** - валідація email адрес
- **Werkzeug 3.1.3** - WSGI утиліти
- **python-dotenv 1.0.0** - робота з змінними середовища

### Frontend технології:
- **Tailwind CSS** - CSS фреймворк для стилізації
- **JavaScript (ES6+)** - динамічна взаємодія на стороні клієнта
- **Font Awesome** - бібліотека іконок

### Інструменти розробки:
- **Git & GitHub** - система контролю версій
- **Visual Studio Code** - редактор коду
- **Postman** - тестування API
- **Swagger UI** - інтерактивна документація API

# Результати тестування в Swagger

### 1. Отримання всіх книг
- **URL:** `/api/v1/books`
- **Метод:** `GET`
- **Опис:** Повертає список усіх книг у системі
- **Приклад запиту:** `GET /api/v1/books`
- **Приклад відповіді:**
```json
{
  "success": true,
  "count": 5,
  "books": [
    {
      "id": 1,

      "author": "Стівен Кінг",

      "stock_quantity": 15,

    }
